# CLAUDE.md - Development Guidelines

## Project Overview
AI SaaS Text-to-Diagram application. 
- **Frontend**: React + Tailwind + React Flow
- **Backend**: Node.js + Express + MongoDB

## Build & Test Commands
- **Frontend**: `npm run dev` (starts on port 3000)
- **Backend**: `npm start` (starts on port 5000)
- **Install dependencies**: `npm install` in respective folders.

## Code Style
- Use functional components and hooks for React.
- Use Tailwind CSS for styling.
- Backend uses CommonJS or ES Modules (to be decided, prefer ES Modules).
- Follow standard ESLint configurations.
