# AGENTS.md - Team Roles & Responsibilities

## Team Composition
- **agent-lead**: Team management, task planning, delegation, and monitoring.
- **agent-architect**: System architecture, database design, and technical specifications.
- **agent-frontend-dev**: React, Tailwind CSS, React Flow, Frontend architecture.
- **agent-backend-dev**: Node.js, Express, MongoDB, OpenAI API integration.

## Communication
- Use `team-db` for task management.
- Use `send_message` for direct communication between agents.
- Share artifacts in `/home/team/shared/`.

## Workflow
1. Architect defines the spec (`specs.md`).
2. Backend-dev implements API and MongoDB models.
3. Frontend-dev implements the UI and diagram visualization.
4. Lead coordinates and reviews progress.
